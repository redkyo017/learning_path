### Exercise 9 — if $\operatorname{rank}(A) = r < n$, the system $Ax=b$ cannot have a unique solution

| Original | Expanded |
|---|---|
| **9.** Row-reduce the augmented matrix $[A \mid b]$ to echelon form $[A' \mid b']$; by Theorem 5.1 this system has the same solutions as the original. Let $r = \operatorname{rank}(A)$, i.e. $A'$ has $r$ nonzero rows, and by hypothesis $r < n$.<br><br>*Case 1: the reduced system is inconsistent*, i.e. some row of $[A' \mid b']$ reads $0 = c$ with $c \neq 0$ (all $A$-entries zero, $b$-entry nonzero). Then no $x$ satisfies that equation, so the system has **no solution** — in particular not a unique one.<br><br>*Case 2: the reduced system is consistent*, i.e. no such contradictory row exists. Among the $n$ variables, exactly $r$ correspond to pivot columns of $A'$ ("pivot variables"); the remaining $n - r \geq 1$ variables correspond to non-pivot columns ("free variables"), since $r < n$. Assign the free variables any values in $\mathbb{R}$ — this is always possible since they appear in no pivot row's leading position — and then the $r$ pivot variables are each uniquely forced by back-substitution through the $r$ pivot equations (each pivot equation determines its pivot variable in terms of variables to its right, which are either already-assigned free variables or already-determined later pivot variables). This produces a valid solution *for every choice* of the $n-r \geq 1$ free variable(s). Since $\mathbb{R}$ has infinitely many elements and $n - r \geq 1$, there are infinitely many distinct choices of the free variable(s), each producing a distinct solution (different free-variable values give different vectors $x$, since those coordinates of $x$ literally are the free variables). So the system has **infinitely many solutions**.<br><br>In both cases the system does not have a unique solution. $\blacksquare$ | **The picture.** Each pivot is a lever that clamps down exactly one variable; each non-pivot column is a dial you can freely turn. "Unique solution" means nothing is left to choose — every variable clamped — which needs one pivot per variable, i.e. $r = n$. The hypothesis $r < n$ says there are only $r$ clamps for $n$ variables, so at least one dial ($n-r \geq 1$ of them) is left loose. A loose dial is fatal to uniqueness in two different ways, which is why the proof splits into two cases. <br><br> **Why row-reduce first.** Theorem 5.1 says the reduced system $A'x=b'$ has *exactly* the same solution set as $Ax=b$, so counting solutions of the (easy-to-read) echelon system counts solutions of the original. The echelon form makes pivots and hence $r=\operatorname{rank}(A)$ (Definition 5.2) visible at a glance. <br><br> **Why the split is exhaustive.** Once in echelon form, either some row is the impossible $0=c$ ($c\neq0$) or none is — there is no third possibility, so Cases 1 and 2 cover everything. Case 1 gives *zero* solutions; Case 2, having $\geq 1$ free dial, gives *infinitely many*. Neither is *one*. <br><br> **Why free choices really are free (Case 2).** The danger would be that assigning a free variable creates a hidden contradiction downstream. It cannot: a free variable sits in a non-pivot column, so it never occupies a leading position in any equation — it only ever appears as a known number on the right-hand side during back-substitution. So any real value works, and each distinct value lands you at a distinct solution vector (that coordinate of $x$ *is* the free variable). Infinitely many inputs, infinitely many outputs. <br><br> **What just happened:** with fewer pivots than unknowns, at least one variable is never pinned down, so the solution set is either empty or an infinite family — never a single point. |

### Exercise 10 — Rouché–Capelli: $Ax=b$ is consistent $\iff$ $\operatorname{rank}([A\mid b]) = \operatorname{rank}(A)$

| Original | Expanded |
|---|---|
| **10.** ($\Leftarrow$) Suppose $\operatorname{rank}([A\mid b]) = \operatorname{rank}(A) = r$. Row-reduce $[A \mid b]$ to echelon form $[A' \mid b']$; then $A'$ (the first $n$ columns) is *a* row echelon form of $A$, so by Theorem 5.2, $A'$ has exactly $r = \operatorname{rank}(A)$ nonzero rows, meaning rows $r+1, \ldots, m$ of $A'$ are entirely zero. Since $\operatorname{rank}([A\mid b]) = r$ too, the augmented matrix $[A'\mid b']$ also has only $r$ nonzero rows — no *additional* pivot appears in the $b'$-column. In particular, for each all-zero row of $A'$ (rows $r+1, \ldots, m$), the corresponding entry of $b'$ must also be $0$: if some such $b'_i \neq 0$, that row $[0,\ldots,0 \mid b'_i]$ would itself be a nonzero row of $[A'\mid b']$ with a pivot in the augmented column, forcing $\operatorname{rank}([A\mid b]) \geq r+1$, contradicting $\operatorname{rank}([A\mid b])=r$. So every one of those rows reads $0 = 0$ — no contradiction. The remaining $r$ pivot rows can always be satisfied by back-substitution (as in Exercise 9's Case 2, assigning free variables arbitrarily and solving pivot variables in terms of them). Hence a solution exists: the system is **consistent**.<br><br>($\Rightarrow$) Suppose $Ax = b$ is consistent, so it has at least one solution $\bar{x}$. Row-reduce $[A \mid b]$ to echelon form $[A' \mid b']$ using the same operations that reduce $A$ to $A'$ (a row echelon form of $A$, with $\operatorname{rank}(A) = r$ nonzero rows by Theorem 5.2); by Theorem 5.1, $\bar x$ is also a solution of the reduced system $A'x = b'$. Suppose toward a contradiction that $\operatorname{rank}([A\mid b]) > \operatorname{rank}(A) = r$: since $A'$ has only $r$ nonzero rows, this means some row $i > r$ of $[A' \mid b']$ — which is entirely zero in its $A'$-part (rows past the $r$-th are zero in $A'$) — is nonzero overall, i.e. has $b'_i \neq 0$. That row reads $0 = b'_i \neq 0$, which $\bar x$ cannot satisfy — contradicting that $\bar x$ solves the reduced system. So no such row exists, and $\operatorname{rank}([A\mid b]) = \operatorname{rank}(A)$.<br><br>Both directions hold, proving the equivalence. $\blacksquare$ | **The one idea behind both directions.** Gluing $b$ on as an extra column can only ever *keep or raise* the pivot count, so $\operatorname{rank}([A\mid b]) \geq \operatorname{rank}(A)$ always. It rises — by exactly one — precisely when reduction produces a row that is all zeros across $A'$ but has a nonzero entry in the $b'$ slot, i.e. the impossible row $0 = (\text{nonzero})$. That single row is *both* "an extra pivot in the $b$-column" *and* "the system is inconsistent." Rouché–Capelli is just this coincidence stated twice: the ranks are equal $\iff$ no such row exists $\iff$ the system is consistent. Everything below is bookkeeping around that equivalence. <br><br> **($\Leftarrow$) direction, in words.** Equal ranks means $b$ added no new pivot, so no row of $[A'\mid b']$ can read $0=(\text{nonzero})$ — if one did, it would be an extra pivot and push $\operatorname{rank}([A\mid b])$ to $r+1$. With that landmine ruled out, every zero row of $A'$ is harmlessly $0=0$, and the genuine $r$ pivot equations solve by back-substitution (Exercise 9, Case 2). A solution exists. Theorem 5.2 is what lets us say $A'$ has *exactly* $r$ nonzero rows regardless of how we reduced. <br><br> **($\Rightarrow$) direction, in words.** Run it backwards: if a solution $\bar x$ exists, it survives reduction unchanged (Theorem 5.1 — row ops preserve the solution set). But a solution cannot satisfy $0=(\text{nonzero})$, so that fatal row simply cannot be present; with it absent, $b$ contributed no extra pivot and the ranks match. <br><br> **What just happened:** consistency is exactly the absence of a contradictory zero-row, and that contradictory row is the *only* thing that can make the augmented matrix out-rank $A$ — so "solvable" and "same rank" are two names for the same condition. |
