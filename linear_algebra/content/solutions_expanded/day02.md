### Exercise 5 — more than $\dim V$ vectors are always dependent

| Original | Expanded |
|---|---|
| Let $\{u_1, \dots, u_n\}$ be *some* basis of $V$ (it exists since $\dim V = n$ means $V$ is finite-dimensional with a basis of size $n$); in particular it spans $V$. Let $\{w_1, \dots, w_m\}$ be any set of $m > n$ vectors in $V$, and suppose toward contradiction it is linearly independent. Lemma 2.3, applied with the spanning set $\{u_1,\dots,u_n\}$ and the independent set $\{w_1,\dots,w_m\}$, gives $m \le n$ — contradicting $m > n$. So $\{w_1,\dots,w_m\}$ cannot be linearly independent; it is dependent. $\blacksquare$ | **The one idea driving this.** Lemma 2.3 (Steinitz) says the same thing every time: an independent set can never outnumber a spanning set. Here a basis of $V$ is, by Definition 2.2, both spanning *and* of size exactly $n$ — so it is a spanning set of size $n$ that caps how large any independent set can be. <br> **Why the contradiction lands.** We only get to *use* Lemma 2.3 if its two hypotheses hold: a spanning set (the basis $\{u_1,\dots,u_n\}$, guaranteed by $\dim V=n$) and an independent set (the assumed-independent $\{w_1,\dots,w_m\}$). The lemma then forces $m\le n$, which collides head-on with the premise $m>n$. The only assumption we made freely was "the $w$'s are independent," so that is what must be false. <br> **Geometric read.** $V$ has only $n$ genuinely independent directions to offer; you cannot fit $m>n$ vectors that all point in "new" directions — one of them must be reachable from the others. <br> **What just happened:** because a basis is a spanning set of size $n$ and nothing independent can beat a spanning set in size, any $m>n$ vectors are forced to be dependent by count alone. |

### Exercise 6 — every independent set extends to a basis

| Original | Expanded |
|---|---|
| Let $\{v_1, \dots, v_k\}$ be linearly independent in a finite-dimensional $V$ with $\dim V = n$. We build up a basis containing it. If $\operatorname{span}\{v_1,\dots,v_k\} = V$, then $\{v_1,\dots,v_k\}$ already spans $V$ and is independent, hence is itself a basis — done. Otherwise $\operatorname{span}\{v_1,\dots,v_k\} \neq V$, so there exists some $w_1 \in V \setminus \operatorname{span}\{v_1,\dots,v_k\}$. *Claim:* $\{v_1,\dots,v_k,w_1\}$ is linearly independent. Indeed, suppose $a_1v_1 + \cdots + a_kv_k + b w_1 = 0$. If $b \neq 0$, we could solve $w_1 = -\frac1b(a_1v_1+\cdots+a_kv_k) \in \operatorname{span}\{v_1,\dots,v_k\}$, contradicting the choice of $w_1$. So $b = 0$, leaving $a_1v_1+\cdots+a_kv_k = 0$, which forces $a_1=\cdots=a_k=0$ by independence of $\{v_1,\dots,v_k\}$. So all coefficients are zero, proving the claim. Now repeat this process on $\{v_1,\dots,v_k,w_1\}$: either it already spans $V$ (done, it's a basis extending the original set), or we can again find a vector outside its span and adjoin it while preserving independence, exactly as above. Each step increases the size of the independent set by 1. By Exercise 5 (equivalently Lemma 2.3), no linearly independent set in $V$ can have more than $n = \dim V$ elements, so this process cannot continue past $n$ steps total — it must terminate with a spanning independent set, i.e., a basis, of size $\le n$, containing the original $\{v_1,\dots,v_k\}$. $\blacksquare$ | **The mirror image of Theorem 2.2.** Theorem 2.2 *shrinks* an oversized spanning set down to a basis by deleting redundant vectors. This proof runs the same movie backwards: it *grows* an undersized independent set up to a basis by adjoining fresh vectors. A basis is exactly where the two processes meet — independent *and* spanning. <br> **Why adjoining a vector from outside the span keeps independence.** Pick $w_1$ that is genuinely new (not already reachable, i.e. outside the span). In any relation $a_1v_1+\cdots+a_kv_k+bw_1=0$, the coefficient $b$ can't be nonzero: dividing by it would express $w_1$ as a combination of the old $v$'s (contradicting Theorem 2.1's characterization — $w_1$ would then *be* a combination of the others, so it wasn't really outside the span). With $b=0$ the relation collapses to one among the original independent vectors, which forces all remaining coefficients to $0$. So no new dependence is created — the intuition is "a truly new direction can't be faked from the old ones." <br> **Why the loop must stop.** Each round adds exactly one vector, so the independent set's size climbs $k, k{+}1, k{+}2,\dots$. Exercise 5 caps any independent set at $n=\dim V$ vectors, so the climb hits a ceiling after at most $n-k$ steps. It can only stop by *spanning* $V$ (the "done" branch), and a spanning independent set is a basis by Definition 2.2. <br> **What just happened:** starting from independent vectors, we repeatedly bolt on a genuinely new direction — never breaking independence — until the space is filled, and the dimension ceiling guarantees we get there in finitely many steps with a basis that still contains the original set. |

### Exercise 9 — spanning + the right count $\Rightarrow$ basis, for free

| Original | Expanded |
|---|---|
| Suppose toward contradiction that $\{v_1,\dots,v_n\}$ is linearly *dependent*. Then by Theorem 2.2's proof technique, some $v_i$ is a linear combination of the rest, and removing it leaves a spanning set $\{v_1,\dots,v_n\}\setminus\{v_i\}$ of size $n - 1$ with $\operatorname{span}(\{v_1,\dots,v_n\}\setminus\{v_i\}) = \operatorname{span}\{v_1,\dots,v_n\} = V$. Now let $\{u_1,\dots,u_n\}$ be any basis of $V$ (exists since $\dim V = n$); in particular it's a linearly independent set of size $n$. Applying Lemma 2.3 with the spanning set $\{v_1,\dots,v_n\}\setminus\{v_i\}$ (size $n-1$) and the independent set $\{u_1,\dots,u_n\}$ (size $n$) gives $n \le n - 1$ — a contradiction. So $\{v_1,\dots,v_n\}$ cannot be dependent; it is independent, and since it also spans $V$ by hypothesis, it is a basis. $\blacksquare$ | **What this buys you.** Checking a basis normally means verifying two things: spanning *and* independence. This result says that when you already have spanning *and* the vector count equals $\dim V$, independence comes for free — no second check needed. That is the practical payoff worth remembering. <br> **The mechanism.** If the spanning set were dependent, Theorem 2.2's deletion step would let you throw away a redundant vector and *still span $V$* — but now with only $n-1$ vectors. That is a spanning set that has become "too small." Meanwhile a basis of $V$ is an independent set of the full size $n$. Feeding these to Lemma 2.3 (spanning set of size $n-1$, independent set of size $n$) demands $n\le n-1$, which is impossible. So the assumed dependence can't happen. <br> **Why the count is the crux.** The whole squeeze works only because the count is exactly $n=\dim V$: dropping one vector pushes the spanning set *below* $n$, and $n$ is precisely the size of an independent set (a basis) that no smaller spanning set can support. With more than $n$ vectors this argument wouldn't corner you. <br> **What just happened:** at exactly the dimension count, a spanning set has no slack — it can't afford to lose a redundant vector without dropping below the size a basis needs, so it is forced to be independent and hence itself a basis. |
