### Exercise 16 — $Ax=0$ has a nontrivial solution $\iff \operatorname{rank}(A) < n$

| Original | Expanded |
|---|---|
| **16.** Let $r = \operatorname{rank}(A)$, and row-reduce $A$ to an echelon form $U$ with $r$ pivots ($r \le n$); by Theorem 5.1, $Ax=0 \iff Ux=0$, so it suffices to analyze $Ux=0$. Among the $n$ variables, exactly $r$ are pivot variables and $n - r$ are free variables (those in non-pivot columns). <br> ($\Leftarrow$) Suppose $r < n$. Then $n - r \ge 1$, so at least one free variable exists. Assign it the value $1$ (and any other free variables the value $0$); each pivot variable is then uniquely determined by back-substitution through the $r$ pivot equations (all of which read "$\ldots = 0$" since the system is homogeneous). This produces a solution $x$ whose free-variable coordinate is $1 \neq 0$, so $x \neq 0$ — a nontrivial solution exists. <br> ($\Rightarrow$) Suppose $r = n$ (the only remaining case, since $r \le n$ always). Then every column is a pivot column, so there are no free variables: the $r=n$ pivot equations, read from the bottom pivot row upward, force each variable to equal an expression in variables to its right that are already forced to $0$ (starting from the last pivot equation, which involves only the last variable and reads $c \cdot x_n = 0$ with $c \neq 0$, forcing $x_n = 0$; then the second-to-last pivot equation involves only $x_{n-1}$ and the already-zero $x_n$, forcing $x_{n-1}=0$; and so on). Hence $x = 0$ is the *only* solution — no nontrivial solution exists. Contrapositive: if a nontrivial solution exists, $r \neq n$, i.e. (combined with $r \le n$) $r < n$. <br> Both directions give: $Ax=0$ has a nontrivial solution $\iff r < n$. $\blacksquare$ | **Intuition — rank counts constraints, free variables count wiggle room.** Row reduction (Theorem 5.1) leaves the solution set untouched, so the whole question is really about $U$. Each pivot is one genuinely independent equation that pins down one variable; the $n-r$ non-pivot columns are variables that nothing pins down — the system's leftover degrees of freedom. <br> **Why $r<n$ forces a nonzero solution.** $r<n$ means at least one free variable exists. "Free" means you may set it to *anything* and still solve for the rest, so set it to $1$. Because the system is homogeneous, every pivot equation reads "$\dots=0$", so back-substitution merely fills in the pivot variables to match — nothing can override the $1$ you planted. The result is a genuine solution carrying a nonzero coordinate. Geometrically a free direction is a whole line of solutions through the origin, not just the origin itself. <br> **Why $r=n$ forces only zero.** With no free columns every variable is a pivot variable. Read bottom-up: the last pivot equation pins $x_n=0$, which makes the next pin $x_{n-1}=0$, cascading upward until every variable is $0$ — the origin is the lone solution. The two cases are exhaustive because $r\le n$ always. <br> **What just happened:** more unknowns than pivots ($r<n$) always leaves a free direction you can slide along, producing a nonzero solution; when the pivots use up every column ($r=n$) there is nothing to slide, so only $x=0$ survives. |

### Exercise 17 — scaling one basis vector by $c\neq0$ leaves a basis

| Original | Expanded |
|---|---|
| **17.** *Spanning.* Since $c \neq 0$, $v_1 = \tfrac1c(cv_1)$, so $v_1 \in \operatorname{span}\{cv_1, v_2, \dots, v_n\}$; combined with $v_2, \dots, v_n$ trivially being in that span, every original basis vector is in $\operatorname{span}\{cv_1,v_2,\dots,v_n\}$, so $V = \operatorname{span}\{v_1,\dots,v_n\} \subseteq \operatorname{span}\{cv_1,v_2,\dots,v_n\}$ (Day 1's monotonicity fact). The reverse inclusion is immediate since $cv_1$ is itself a linear combination (scalar multiple) of $v_1$, so $\operatorname{span}\{cv_1,v_2,\dots,v_n\} \subseteq \operatorname{span}\{v_1,\dots,v_n\} = V$. Hence $\operatorname{span}\{cv_1,v_2,\dots,v_n\} = V$: the set spans $V$. <br> *Independence.* Suppose $a_1(cv_1) + a_2v_2 + \cdots + a_nv_n = 0$ for scalars $a_i$. Rewrite as $(a_1c)v_1 + a_2v_2 + \cdots + a_nv_n = 0$. Since $\{v_1,\dots,v_n\}$ is linearly independent, every coefficient must vanish: $a_1 c = 0$ and $a_2 = \cdots = a_n = 0$. Since $c \neq 0$, $a_1c=0$ forces $a_1 = 0$ as well. So the only solution is trivial: $\{cv_1,v_2,\dots,v_n\}$ is linearly independent. <br> Spanning and independent: $\{cv_1,v_2,\dots,v_n\}$ is a basis of $V$. $\blacksquare$ | **Intuition — rescaling one axis changes units, not the frame.** A basis is a coordinate frame; multiplying $v_1$ by a nonzero $c$ stretches (or flips) the first axis without rotating it or flattening it onto the others. Every vector you could name before you can still name — you just re-read its first coordinate in new units. The proof is making "a nonzero stretch is reversible" precise. <br> **Why spanning survives.** Anything you can build from $cv_1$ you can build from $v_1$ (it's a multiple of it), and conversely $v_1 = \tfrac1c(cv_1)$ — and that division is legal *only* because $c\neq0$. So the two sets generate exactly the same combinations, giving equal spans by double inclusion (Day 1's monotonicity fact). <br> **Why independence survives.** Any dependence among $\{cv_1,v_2,\dots\}$ becomes, once $c$ is absorbed into the first coefficient, a dependence among the *original* basis $\{v_1,\dots,v_n\}$. Independence of the original kills every coefficient, including $a_1c$; then $c\neq0$ peels off the $c$ to give $a_1=0$ too. Once more $c\neq0$ is the hinge: a zero $c$ would collapse the first axis and destroy both properties. <br> **What just happened:** scaling a basis vector by a nonzero number is just a reversible relabelling of one axis, so the set still spans $V$ and stays independent — it is still a basis. |

### Exercise 19 — surjective + equal (finite) dimension $\Rightarrow$ injective

| Original | Expanded |
|---|---|
| **19.** Suppose $T: V \to W$ is surjective, so $\operatorname{im} T = W$, hence $\dim(\operatorname{im} T) = \dim W$. Let $n = \dim V = \dim W$. By the rank-nullity theorem (Theorem 4.1), $\dim(\ker T) + \dim(\operatorname{im} T) = \dim V \implies \dim(\ker T) + n = n \implies \dim(\ker T) = 0.$ A subspace of dimension $0$ is exactly $\{0\}$ (only the zero vector spans a $0$-dimensional space — any nonzero vector alone spans at least a $1$-dimensional subspace), so $\ker T = \{0\}$. By Lemma 4.1 (injective iff trivial kernel), $T$ is injective. $\blacksquare$ | **Intuition — a fixed dimension budget, spent on image or kernel.** Rank–nullity (Theorem 4.1) says the $\dim V$ dimensions of the input split cleanly into two piles: $\dim(\ker T)$ dimensions that get crushed to $0$, and $\dim(\operatorname{im} T)$ dimensions that survive as output. The total is fixed at $\dim V$. <br> **Why surjectivity empties the kernel.** Surjective means the image fills all of $W$, so it already claims $\dim W = n$ of the budget. Since the budget is only $n$ (because $\dim V = \dim W$), nothing is left for the kernel: $\dim(\ker T)=0$. This is exactly where equal dimension is essential — if $W$ were smaller than $V$, filling $W$ would not exhaust $V$'s budget and a kernel could hide in the surplus. <br> **Why dimension $0$ means a trivial kernel.** A $0$-dimensional subspace contains no independent vector at all, so it can only be $\{0\}$; any nonzero vector would already span a line. Trivial kernel is precisely injectivity (Lemma 4.1). <br> **What just happened:** being onto spends the entire dimension budget on the output side, leaving zero dimensions to collapse — so between spaces of equal finite dimension, surjective automatically drags injective along with it. |

### Exercise 20 — full row rank $\Rightarrow N(A^T)=\{0\}$

| Original | Expanded |
|---|---|
| **20.** Since $\operatorname{rank}(A) = m$ equals the number of rows, the row-reduction argument of Lemma 6.1(a) shows the $m$ rows of $A$ are themselves already linearly independent (row-reducing an $m\times n$ matrix to echelon form with $m$ pivots means every row becomes, and remains, a pivot row — no row is ever reduced to all zeros). Now suppose $y \in N(A^T)$, i.e. $A^Ty = 0$, equivalently $y^TA = 0$. Writing out $y^TA$ as a linear combination of the rows $r_1, \dots, r_m$ of $A$: $y^TA = \sum_{i=1}^m y_i\, r_i = 0.$ Since $r_1, \dots, r_m$ are linearly independent, this forces every coefficient to vanish: $y_i = 0$ for all $i = 1, \dots, m$, i.e. $y = 0$. Hence $N(A^T) = \{0\}$. $\blacksquare$ (Cross-check via the Fundamental Theorem: $\dim N(A^T) = m - r = m - m = 0$, consistent.) | **Intuition — the left null space asks "which row-combinations cancel?"** The condition $A^Ty=0$ is the same as $y^TA=0$, and $y^TA$ is precisely the linear combination $y_1 r_1 + \dots + y_m r_m$ of $A$'s rows. So $N(A^T)$ collects exactly the coefficient vectors $y$ that make the rows cancel to zero — it is the catalogue of dependences among the rows. <br> **Why full row rank kills all of them.** Rank $=m$ means all $m$ rows are independent: row reduction leaves $m$ pivot rows and never zeroes one out (Lemma 6.1a). Independence says the *only* recipe that mixes the rows down to $0$ is the all-zero recipe, so every $y_i=0$, i.e. $y=0$. This is the mirror image of full *column* rank: there, independent columns force the ordinary null space $N(A)=\{0\}$; here, independent rows force the left null space $N(A^T)=\{0\}$. <br> **Why the count agrees.** The Fundamental Theorem gives $\dim N(A^T)=m-r$; with $r=m$ this is $0$, and a $0$-dimensional space is $\{0\}$ — the identical conclusion reached by dimension-counting instead of by independence. <br> **What just happened:** when every row is independent, no nonzero recipe can blend the rows into zero, so the left null space collapses to just the zero vector. |
