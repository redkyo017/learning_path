## Confusable pairs

- bra / ket — a ket $|\psi\rangle$ is a column vector; a bra $\langle\psi|$ is its conjugate-transpose row vector, not a separate kind of object.
- superposition / entanglement — superposition is a property of a single system's state vector; entanglement is a property of how two or more subsystems' states are correlated (a superposition can exist with zero entanglement).
- unitary / Hermitian — unitary ($U^\dagger U=I$) preserves inner products and represents evolution; Hermitian ($A=A^\dagger$) has real eigenvalues and represents an observable — a matrix can be one, both (Pauli matrices), or neither.
- pure state / mixed state — a pure state's density matrix is rank 1 (one definite state vector); a mixed state's has two or more nonzero eigenvalues (classical uncertainty over quantum states).
- gate / measurement — a gate is a deterministic, reversible unitary evolution; a measurement is a probabilistic, irreversible collapse — conflating them is the single most common source of confusion about "what quantum parallelism gives you."
- global phase / relative phase — an overall factor $e^{i\gamma}$ multiplying an entire state vector is physically unobservable; a relative phase between two amplitudes (e.g. the sign distinguishing $|+\rangle$ from $|-\rangle$) is physically real and detectable via interference.
- separable / entangled — separable states factor as a tensor product of subsystem states; entangled states provably do not, which is exactly what the Bell-state non-factorization proofs (Days 7, 9) establish.
- oracle reflection ($O_f$) / diffusion operator ($D$) — both are reflections used in one Grover iteration, but $O_f$ reflects about $|bad\rangle$ (depends only on which items are marked) while $D$ reflects about $|s\rangle$ (depends only on the state-preparation step, not the oracle).
- BPP / BQP — BPP allows classical randomness with bounded error; BQP allows quantum superposition/interference with bounded error, and $BPP\subseteq BQP$ is proven but not known to be strict.
- amplitude / probability — an amplitude (e.g. $\alpha,\beta$) is a complex number that can interfere (add or cancel); a probability is its squared modulus via the Born rule, always non-negative and never itself interferes.
- multiplicative order ($r$) / Euler's totient ($\varphi(N)$) — $r$ is the specific smallest exponent with $a^r\equiv1\pmod N$ for a chosen $a$; $\varphi(N)$ is the size of the whole group $\mathbb{Z}_N^*$, and Euler's theorem/Lagrange's theorem guarantees only that $r\mid\varphi(N)$, not that they're equal.
