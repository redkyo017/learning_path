# Network Engineering Mastery — Journal

One shared file for all seven days. Copy the template block under each day's heading
and fill it in. Write the evidence chain *before* you fix anything.

## Template

```markdown
**Day:** N — <title>

**Header I drew from memory, and what I got wrong:**
<Which header or state machine you drew on the blank page. List every field or state
you missed, misplaced or misnamed, after correcting against the content.>

**Evidence chain for the break (written before fixing):**
1. Symptom: <the line break.sh printed>
2. Observation: <command run -> the capture line, table entry or counter it showed>
3. Observation: <next command -> what it showed, and what it ruled out>
4. Conclusion: <the header field or state that proves the cause>
5. Planned fix: <one line, written before you touch anything>

**The AWS sentence:**
"<X> in AWS is <Y> on the wire."
```
