# Day 46 — Full mock 4

**Phase:** 4 — Simulation | **Total:** 2h15 | **New cards:** 0

## Why this matters

Today is a full mock, Mock 4 of six, and the one that shows whether yesterday's rewritten
Schreiben answers hold under real timing rather than in an untimed rewrite. The exam
itself does not care which module you patched most recently — it scores all four the same
way, so today runs exactly like day 44 did.

## Core concepts

Same non-modular scoring as day 44: four modules out of 25 each, one combined total out
of 100, pass at 60. No module passes or fails on its own.

### Block 1 — Anki (25 min)

Review only, 0 new cards. Clear the backlog before anything else.

### Block 2 — Input (40 min)

Open the next Übungssatz you have not sat yet, from
https://www.goethe.de/en/spr/kup/prf/prf/sd1/ueb.html — and if no unseen set is left,
re-sit one under the Übungssatz-supply rule in `runbook.md` §Mock papers and the Übungssatz supply, which is likeliest to
bite today. Run Hören, then Lesen, back to back, each timed as printed on the paper.
Pacing is today's focus: mark the point in Lesen where your accuracy starts to slip — the
item number you were on when you began guessing rather than reading — and write it next to
the score.

### Block 3 — Output (40 min)

Run the Schreiben module timed, Teil 1 and Teil 2, using only the exam paper — save
`templates/schreiben_templates.md` for scoring afterward. Check the three Leitpunkte at
minute 7 of Teil 2, not at the end: today is the sitting where you prove that check
happens while there is still time to fix a gap.

### Block 4 — Exam drill (30 min)

Run the Sprechen module timed and recorded, all three Teile, then score every module and
log Hören/25, Lesen/25, Schreiben/25, Sprechen/25 and the total /100 in
`progress_tracker.md`'s Mock log as Mock 4 (day 46). Start today's error log for day 47's
patching.

Do not settle for a remembered description of each one — read the three Teil headers and instructions on today's paper, write down in your own words what each actually asks you to do, and check your recital against that before starting the clock.
2. 3. After scoring, compare today's total to your last two mocks (day 42, day 44) and note the trend. — **Hint:** three points make a trend; two do not. — **Solution sketch:** write all three totals next to each other in `progress_tracker.md`'s Mock log — e.g. 58, 63, 67 — and note whether the trend is rising, flat, or falling before day 47's patching decides where to focus.

## Anti-patterns / Common mistakes

- Skipping Block 1's review because "it's a mock day." Reviews still come due regardless of what the rest of the day holds, and skipping them now stacks a backlog exactly when day 47's Sprechen re-recording needs your full attention instead.
- Rushing or skipping a Sprechen Teil because you're confident with it already. Every Teil is scored inside the same /25, with no partial credit for a skipped one — run all three, timed, every mock, no exceptions.

## Minimum viable day

Same exception as day 44: a full mock cannot be split. If you cannot run the whole
session, do Block 1 only (25 min) and move the entire mock, unstarted, to your next
session. See `runbook.md` §Bad days for the general rule this overrides on mock days.
