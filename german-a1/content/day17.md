## Core concepts

No new grammar today. Instead, run a fast self-check across the twelve reflexes from
days 4–16 — for each one, produce one sentence aloud from memory, no notes:

```
sein          → Ich bin müde.
haben         → Ich habe einen Bruder.
regular verbs → Meine Mutter wohnt in Hanoi.
W-question    → Wo wohnst du?
yes/no        → Kommst du um sieben Uhr?
Akkusativ     → Ich habe einen Balkon.
nicht/kein    → Ich habe keinen Garten.
possessive    → Ist das Ihr Kaffee?
separable     → Ich stehe um sieben Uhr auf.
um/am/im      → Der Termin ist am Montag um neun Uhr.
es gibt       → Es gibt einen Arzt in der Nähe.
imperative    → Öffnen Sie bitte das Fenster.
```

If any line stalls, that's the reflex to review tonight from its own day file before
Phase 2 starts.

## Exercises

1. Produce all twelve reflex sentences from the Core concepts list aloud, from memory, timing yourself. — **Hint:** don't reread the list before starting — the point is retrieval speed, not recognition; a sentence you have to re-read first is a sentence you don't actually have yet. — **Solution sketch:** `Ich bin müde. Ich habe einen Bruder. Wo wohnst du? Ich habe keinen Garten. Der Termin ist am Montag um neun Uhr. Öffnen Sie bitte das Fenster.` — six of the twelve, produced cold; run the remaining six the same way, and any sentence that takes more than three seconds to start is your review target tonight.
2. Deliver the Teil 1 script from memory three times in a row without a single stall, timing each attempt. — **Hint:** the exam does not allow a restart — if you train restarts as normal, you'll reach for one under real pressure; instead, if you stall, keep going and note the gap for correction afterward. — **Solution sketch:** `Ich heiße [Vorname] [Nachname]. Ich bin [Alter] Jahre alt. Ich komme aus [Land]. Ich wohne in [Stadt]. Ich spreche [Sprache] und ein bisschen Deutsch. Ich bin [Beruf] von Beruf. Mein Hobby ist [Hobby].` — three unbroken takes, timed, is the pass condition, not one lucky take.
3. From today's new words (theme 08_travel, words 351–375), pick five nouns and produce article plus plural from memory. — **Hint:** this is the last new-word slice of Phase 1 — treat any hesitation here as tonight's review priority, since the travel theme runs straight into tomorrow's Perfekt drills. — **Solution sketch:** e.g. `das Taxi, die Taxis; die Grenze, die Grenzen; der Ausweis, die Ausweise` — say each pair aloud twice, then check the wordlist.

## Anti-patterns / Common mistakes

- Treating "recited from memory" loosely — glancing at the script mid-recitation and calling it a memory attempt. The checkpoint gate is unhesitating and from memory; a single glance at the page invalidates the attempt, so keep the script closed or out of sight entirely.
- Logging the checkpoint in `progress_tracker.md` as done before actually recording a clean, unhesitating take. The tracker is the source of truth for your own pacing — logging an attempt that still stalled quietly resets your own baseline for what "done" means on every later checkpoint.
