# Day 47 — Patching the day-46 error log; re-recording Sprechen

**Phase:** 4 — Simulation | **Total:** 2h15 | **New cards:** 0

## Why this matters

No new material today, same rule as every patching day this phase. You work the day-46
error log end to end, with Sprechen getting the dedicated fix: any answer that stalled —
where you paused, restarted, or went silent — gets re-recorded until the stall is gone,
because Sprechen is the one module the exam does not let you pause and rethink.

## Core concepts

Same error-log format as day 43 and day 45. Today's dedicated fix targets every Sprechen
answer that stalled in the day-46 mock — you re-record the underlying frame from
`templates/sprechen_scripts.md`, not just the one question that happened to come up.

### Block 1 — Anki (25 min)

Review only, 0 new cards. Clear the backlog.

### Block 2 — Input (40 min)

Go through the day-46 error log module by module and write the likely cause next to each
miss.

### Block 3 — Output (40 min)

Re-record every Sprechen answer that stalled. Pull the relevant frame from
`templates/sprechen_scripts.md` — Teil 1, Teil 2, or Teil 3, whichever the stall was in —
say it aloud five times, and record the fifth attempt. Compare it to the mock recording
for hesitation and filler words.

### Block 4 — Exam drill (30 min)

Run a timed mini Sprechen mock, all three Teile, using your patched answers, recorded
straight through with no pauses to think.

## Exercises

1. A common day-46 stall: you froze mid-spelling on the letter "ß" while spelling "Straße" aloud. — **Hint:** `ß` appears only once in the alphabet table and is under-rehearsed compared to common letters. — **Solution sketch:** `S-T-R-A-ß-E — es, te, er, a, Eszett, e.` Say the full alphabet line three times, slowing only on `ß`.
2. A common day-46 stall: you hesitated between "zwei" and "zwo" mid-number. — **Hint:** per `templates/sprechen_scripts.md`, say `zwei` throughout — it is the default and it is what the Hören audio uses. `zwo` is only a fallback if the examiner mishears you, and switching between the two mid-number is what causes the stall. — **Solution sketch:** `Meine Nummer ist null eins sieben null, zwei drei vier, fünf sechs sieben acht.` Re-record the full number with `zwei` every time.
3. A common day-46 stall: you froze partway through a Teil 3 request about a window. — **Hint:** an incomplete request frame from `templates/sprechen_scripts.md`'s Teil 3. — **Solution sketch:** `Können Sie bitte das Fenster öffnen?` Re-record the full sentence, then answer it with all three response frames in turn.

## Anti-patterns / Common mistakes

- Rehearsing the stalled answer silently in your head instead of recording it. Per `STRATEGY.md`'s "delaying speaking until ready" mistake, only a recording forces real production and shows whether the stall is actually gone.
- Patching only the exact question that came up in the mock instead of the underlying frame. The real exam draws a different keyword card each sitting, so fixing one memorised sentence doesn't fix the pattern — drill the frame in `templates/sprechen_scripts.md` with several different fillers.
