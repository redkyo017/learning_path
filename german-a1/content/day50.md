# Day 50 — Full mock 6 — the booking decision

**Phase:** 4 — Simulation | **Total:** 2h15 | **New cards:** 0

## Why this matters

This is the final full mock of the path, Mock 6 of six, and the day the whole 50-day plan
has been pointing at. Score it exactly like the other five, then use the score — nothing
else — to decide what happens next: book the real exam, repeat this phase once, or go
back further. The decision belongs to the number, not to how the day felt.

## Core concepts

Same non-modular scoring as every mock this phase: four modules out of 25 each, one
combined total out of 100. Today's own gate, from `progress_tracker.md`'s Checkpoints
table, is 75+. Score first, decide after — in that order, never the reverse.

### Block 1 — Anki (25 min)

Review only, 0 new cards — the last review-only session before the decision. Clear the
backlog before anything else.

### Block 2 — Input (40 min)

Open the last Übungssatz you have not sat yet, from
https://www.goethe.de/en/spr/kup/prf/prf/sd1/ueb.html — and if no unseen set is left,
re-sit one under the Übungssatz-supply rule in `runbook.md` §Mock papers and the Übungssatz supply, marking today's score
as a re-sit so the branch below is read for what it is. Today is the dress rehearsal, so
the conditions count as much as the number: run the exam-day arrival ritual you wrote on
day 49 first — ID and pens on the table, phone off and stored away, two quiet minutes
seated — and only then start Hören, then Lesen, back to back, each timed as printed on the
paper.

### Block 3 — Output (40 min)

Run the Schreiben module timed, Teil 1 and Teil 2, using only the exam paper, with the
same no-break, no-consultation discipline you would have in the room. This is the last
Schreiben you write before the booking decision — nothing about it should be easier than
the real one.

### Block 4 — Exam drill (30 min)

Run the Sprechen module timed and recorded, all three Teile. Score every module and log
Hören/25, Lesen/25, Schreiben/25, Sprechen/25 and the total /100 in
`progress_tracker.md`'s Mock log as Mock 6 (day 50), and in the Day 50 row of the
Checkpoints table. Then apply the branch in Done when below.

Bei 60 bis 74 Punkten wiederhole ich die Tage 43 bis 50. Unter 60 Punkten gehe ich zurück zu Tag 32.` Write this down before starting Block 2.

Mein Hobby ist [Hobby].` Play both recordings back to back.
3. After scoring, write your total next to Mock 6 (day 50) before doing anything else, then apply the matching branch from Done when. — **Hint:** the branch is decided by the number you just wrote, not by how the mock felt while you were taking it. — **Solution sketch:** write the total first — e.g. 78/100 — then go to Done when and follow the 75+ line, not a line you'd prefer.

## Anti-patterns / Common mistakes

- Deciding whether to book the exam before finishing the scoring and logging. Score every module, write the total in `progress_tracker.md`, and only then open Done when below — never the other way round.
- Treating a 75+ result as "finished with German" and dropping Anki before the real exam. Reviews keep running in the days between today and the booked exam date, so the 650 Tier 1 and 320 Tier 2 words don't decay before test day.

## Minimum viable day

Same exception as every mock day this phase: a full mock cannot be split. If you truly
cannot run the whole session today, do Block 1 only (25 min) and move the entire mock,
unstarted, to tomorrow — do not make the booking decision on a partial or old score. See
`runbook.md` §Bad days for the general rule this overrides on mock days.
