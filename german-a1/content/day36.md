# Day 36 — italki session #2: Teil 3 requests

**Phase:** 3 — Output | **Total:** 2h15 | **New cards:** 32

## Why this matters

Teil 3 is the Sprechen part learners drill least, because requests feel like small talk
rather than "real" exam content. It is scored just like the other two Teile. A second
paid session buys targeted repetition on exactly that gap.

## Core concepts

Teil 3 has two sides — making a request and reacting to one — and the real exam switches
you between them. Today's session drills both, not just the side that feels easier.

### Block 1 — Anki (25 min)

Clear both decks' review queues. Take today's 32 new cards as the next contiguous slice:
words 129–160. Rows 129–131 close `t2_verbs` (`sich entscheiden`, `überlegen`,
`gratulieren`) and rows 132–160 open `t2_adverbs` (`manchmal`, `nie`, `selten`,
`gestern`, `heute`, `morgen`, `schon`, `noch`, `meistens`, `wieder`).

### Block 2 — Input (40 min)

Reread `templates/sprechen_scripts.md`'s Teil 3 section — the five request frames and
three response frames. Then draft the German agenda message for today's call:

```
Hallo! Ich übe für Start Deutsch 1, Sprechen Teil 3 (Bitten formulieren und darauf
reagieren). Können Sie mir bitte 5 Situationskarten geben (z. B. Fenster, Tür, Tasche,
Wasser, Licht)? Ich mache eine Bitte, Sie antworten, dann wechseln wir die Rollen. Die
Sitzung dauert 30 Minuten. Vielen Dank!
```

### Block 3 — Output (40 min)

Book a 30-minute session on https://www.italki.com. Work through five situations, request
then reaction, then switch roles so you practise reacting too. Use at least two of the
three response frames from `templates/sprechen_scripts.md`.

### Block 4 — Exam drill (30 min)

Run the Hören module from the second Übungssatz
(https://www.goethe.de/en/spr/kup/prf/prf/sd1/ueb.html) under full timing again — same set
as day 32, a second pass under real conditions, since a single exposure does not tell you
whether an item was luck or actual comprehension. The ten-day wait in `runbook.md` §Mock
papers and the Übungssatz supply governs re-sitting a whole paper as a scored mock; a
single module re-run four days later is deliberate repetition, not a mock, so it is not
logged in the Mock log and its score is not compared against any gate.

## Exercises

1. Write the German agenda message requesting Teil 3 drilling. — **Hint:** name the number of situation cards you want, so the tutor can prepare them in advance. — **Solution sketch:** the agenda text above, sent before the call.
2. Say all five request frames aloud, each with a different real object in the room. — **Hint:** vary only the object; the sentence shape stays fixed. — **Solution sketch:** `Geben Sie mir bitte das Buch.`
3. After the call, write one Tier 2 word your tutor used that was new to you, in a full sentence. — **Hint:** a word noted without a sentence rarely survives to tomorrow's review. — **Solution sketch:** `Ich überlege noch.`

## Anti-patterns / Common mistakes

- Sending an agenda that just says "practise speaking" instead of naming Teil 3 and the
  number of situation cards — a vague agenda gets a vague session.
- Only ever practising the request side, never the response side. Teil 3 scores both
  directions, and on the real exam day you switch roles with your exam partner partway
  through.

## Minimum viable day

Block 1 + Block 3 only (45 min) — the call is today's Output block, so keep it if it is
booked. If you cannot take the call at all, do Block 1, then say all five Teil 3 request
frames and all three response frames aloud as your Output, and move the call to your next
full session. See `runbook.md` §Bad days.
