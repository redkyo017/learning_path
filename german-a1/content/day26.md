# Day 26 — weil as a memorised chunk

**Phase:** 2 — Expansion | **Total:** 2h15 | **New cards:** 25

## Why this matters

`weil` (because) lets you give a reason — a skill Sprechen and Schreiben both reward, and
one that only requires memorising one fixed pattern, not subordinate-clause theory. You
learn it today as a chunk: `..., weil + fact + verb-at-the-end`, the same way you learned
`mit dem Bus` as a chunk rather than a rule. Today's 25 cards sit wholly inside the
13_freetime theme, which supplies natural reasons to practise on.

## Core concepts

Inside a `weil`-clause, the verb always moves to the very end — learn the whole clause as
one unit, not as two halves joined by a connector.

- `Ich bleibe heute zu Hause, weil es regnet.` (I'm staying home today because it's raining.)
- `Ich trage eine Jacke, weil es kalt ist.` (I'm wearing a jacket because it's cold.)
- `Wir gehen nicht spazieren, weil es stürmt.` (We're not going for a walk because it's stormy.)

### Block 3 — Output (40 min)

Write the same message twice and compare. Using `templates/schreiben_templates.md`,
Teil 2, write a friend a message with three points — you're staying home, what is the
weather like where they are, meet on Friday instead. Draft 1: no `weil` anywhere, plain
sentences only. Draft 2: attach a `weil`-clause to each point. Ten minutes for both drafts
together. Then read them side by side. Draft 2 should read as reasons a person would
actually give; if a clause is there only because the exercise asked for one, cut it —
`weil` bolted onto a sentence that needs no reason reads worse than no `weil` at all.

## Exercises

1. Say "I'm staying home because it's raining" using `weil`. — **Hint:** inside the `weil`-clause, the verb moves to the very end: `..., weil es regnet.` — **Solution sketch:** `Ich bleibe heute zu Hause, weil es regnet.` Check `regnet` is the last word.
2. Say "I'm wearing a jacket because it's cold" using `weil`. — **Hint:** with two elements in the clause (`es`, `kalt`), the verb `ist` still goes last, after both. — **Solution sketch:** `Ich trage eine Jacke, weil es kalt ist.` Check the order is `es kalt ist`, not `es ist kalt`.
3. Combine "we're not going for a walk" with a weil-reason about the storm. — **Hint:** `stürmen` is a one-word verb, so it is automatically last in the clause — nothing changes its position. — **Solution sketch:** `Wir gehen nicht spazieren, weil es stürmt.` Check `stürmt` sits at the very end.

## Anti-patterns / Common mistakes

- Putting the verb in second position inside the `weil`-clause, e.g. `weil es ist kalt` instead of `weil es kalt ist` — the verb goes to the very end inside this chunk, always.
- Treating `weil` as a word you can drop into any sentence — it only introduces a reason for something just said; if there is no reason to give, do not force a `weil`-clause into the message.
