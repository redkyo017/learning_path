# Day 16 — The imperative for Sprechen Teil 3

**Phase:** 1 — Engine | **Total:** 2h15 | **New cards:** 25

## Why this matters

Today's 25 cards finish the work theme and start the travel theme, and the imperative is the exact grammar Sprechen Teil 3 is built
on — every request frame in `templates/sprechen_scripts.md` (`Öffnen Sie bitte …`,
`Geben Sie mir bitte …`) is a formal imperative. You've used these frames since day 11
without naming the pattern; today you name it and drill it as its own reflex, because
Teil 3 gives you no time to construct a request from scratch.

## Core concepts

The [Imperativ](GLOSSARY.md#grammar) at this level only needs the formal `Sie`-form,
which is simple to build: take the `Sie`-form of the verb, and put `Sie` after it
instead of before it.

```
Statement:  Sie öffnen das Fenster.
Imperative: Öffnen Sie das Fenster!  /  Öffnen Sie bitte das Fenster.
```

Separable verbs split the same way you already know from day 13 — the prefix goes to
the end:

```
Sie machen das Fenster zu.  →  Machen Sie bitte das Fenster zu.
```

Add `bitte` to keep every request polite, which is also what the exam expects for a
Teil 3 turn.

## Exercises

1. Turn three `Sie`-statements into polite imperatives. — **Hint:** move the verb to the front and keep `Sie` right after it — the rest of the sentence stays in the same order. — **Solution sketch:** `Sie geben mir das Buch.` → `Geben Sie mir bitte das Buch.` / `Sie kommen um acht Uhr.` → `Kommen Sie bitte um acht Uhr.` / `Sie helfen mir.` → `Helfen Sie mir bitte.`
2. Build one imperative from a separable verb, checking the prefix lands at the end. — **Hint:** the imperative doesn't change the separable-verb pattern from day 13 — the base verb moves to the front, the prefix still goes to the end. — **Solution sketch:** `Sie machen das Fenster zu.` → `Machen Sie bitte das Fenster zu.`
3. From today's new words (words 326–350, closing theme 07_work and opening 08_travel), pick five nouns and produce article plus plural from memory. — **Hint:** the nouns in today's slice are all travel words, and several take an umlaut in the plural — `der Zug → die Züge`, `der Bahnhof → die Bahnhöfe` — so say the plural aloud instead of assuming a plain `-e`. — **Solution sketch:** e.g. `der Zug, die Züge; die Fahrkarte, die Fahrkarten; das Hotel, die Hotels` — say each pair aloud twice, then check the wordlist.

## Anti-patterns / Common mistakes

- Building the imperative by simply dropping the subject from a statement instead of moving the verb to the front — saying `Sie das Fenster öffnen` with no verb movement. The verb must lead the sentence; nothing else marks it as a command.
- Forgetting `bitte`, producing a technically correct but bare command — `Öffnen Sie das Fenster.` with no softener. Teil 3 is scored as a polite social exchange, not a military order; `bitte` is not optional politeness, it's part of the expected form.
