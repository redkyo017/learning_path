# Day 44 — Full mock 3

**Phase:** 4 — Simulation | **Total:** 2h15 | **New cards:** 0

## Why this matters

Today is a full mock: all four modules — Hören, Lesen, Schreiben, Sprechen — run back to
back, timed exactly as the real Start Deutsch 1 paper runs them, the same way day 31 and
day 42 did. This is Mock 3 of the six logged in `progress_tracker.md`'s Mock log, and the
one that tells you whether yesterday's Hören patching actually held under full exam
conditions rather than in an untimed drill.

## Core concepts

Start Deutsch 1 is not modular: each module is scored out of 25, but there is no
per-module pass mark. Only the combined total out of 100 decides pass or fail, at 60.
Score every module today, but judge yourself on the sum, not on any single 25.

Open the next Übungssatz you have not sat yet, from

### Block 3 — Output (40 min)

Run the Schreiben module timed — Teil 1 and Teil 2, both — using only the exam paper

log — module, item, your answer, the correct answer — ready for day 45's patching.

## Anti-patterns / Common mistakes

- Checking `templates/schreiben_templates.md` or `templates/sprechen_scripts.md` mid-module instead of only afterward, for scoring. That does not reflect real exam conditions and gives you a score you cannot trust.
- Stopping the clock partway through a module because you "just need a few more minutes." An untimed mock does not tell you whether you would pass the real paper — it tells you what you can do with no time pressure, which is a different and less useful number.

## Minimum viable day

A full mock cannot be split — a partial, untimed attempt corrupts the score you'd log for
Mock 3. If you cannot run the whole session today, do Block 1 only (25 min) and move the
entire mock, unstarted, to your very next session. This overrides the general Block 1 +
one Output block rule in `runbook.md` §Bad days for mock days specifically.
