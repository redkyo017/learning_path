# TLS/Certificates Mastery Journal

Write one entry per day, right after you finish that day's drills — before
you move on. Five minutes now is worth more than a recap next week. Every
prompt below maps onto the four-check verification order (signature chain →
validity dates → name match → trust anchor) from Day 1; naming which check
was actually involved is usually the fastest way to nail down what you
learned.
